🎯 How to Use

Generating a New Image

1. In the main interface, find the text input box labeled "Prompt" or "Description".

2. Type a detailed description of the image you want to create. For example: "A serene mountain landscape at sunset with a crystal-clear lake reflecting the orange sky"

3. Click the "Generate" button. In a few seconds, your image will appear on the screen.

4. You can download the image to your computer by clicking the download icon below the generated image.

Editing an Existing Image

1. Click the "Upload" button to select an image from your computer.

2. In the prompt box, describe what you want to change. For example: "Make the sky more dramatic with storm clouds" or "Add a red car in the driveway"

3. Click "Edit". Your image will be processed and the edited version will appear.

4. Save your edited image by clicking the download icon.
